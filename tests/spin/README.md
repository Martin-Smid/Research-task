# Spin tests

Five plain Python scripts that check the spin (vector / tensor) part of the solver. Each prints `PASS` or raises
an `AssertionError`. They need the same CUDA/CuPy environment as the simulation. Gravity only, no baryons.

| script | what it checks |
|---|---|
| `test_spin_basis.py` | The polarization tensors of `Wave_vector_class.generate_spin_basis` are the textbook spin-s states (s = 0..4): orthonormal, symmetric, traceless, eigenstates of J_z and J^2, J_+ with Condon-Shortley phases. Pure NumPy, no GPU. |
| `test_spin_rotation_invariance.py` | Mixing the 2s+1 polarization components with a unitary matrix leaves the evolution unchanged (rho and psi' = U psi), spin 1 and 2, 100 steps. A non-mixed control proves the test can tell coupled from uncoupled. |
| `test_spin_scalar_reduction.py` | A spin-s vector whose components share one spatial profile evolves exactly like the scalar field (spin 1, 2, 3; random amplitudes and a single polarization). |
| `test_spin_granule_statistics.py` | Density granule statistics: n = 2s+1 independent white Gaussian polarization fields (N = 64, gravity off) give rho/rho_mean ~ Gamma(n, 1/n), i.e. variance(delta) = 1/n and skewness(delta) = 2/sqrt(n), and these stay unchanged under free evolution (100 steps). Also prints what the code's own amplitudes (one shared spatial profile for all components) give: variance * n = n instead of 1. |
| `test_spin_independent_fields.py` | The opt-in generator `Wave_vector_class(..., independent_fields=True, power_spectrum=None)`: every polarization gets its own Gaussian random field, `psi_m = a_m g_m`, with mass fractions `a_m^2` (equal by default). Checks that the code's own fields reproduce Gamma(n, 1/n) (s = 1, 2, 3, t = 0 and after free evolution), that unequal fractions give variance = sum f_m^2, exact component and total masses, seed reproducibility and uncorrelated components, that the momentum factor is applied exactly once, and that the default path (one shared profile) is unchanged. |

## How to run

From the repository root, with the project venv, one script at a time:

```
python tests/spin/test_spin_basis.py
python tests/spin/test_spin_rotation_invariance.py
python tests/spin/test_spin_scalar_reduction.py
python tests/spin/test_spin_granule_statistics.py
python tests/spin/test_spin_independent_fields.py
```

(Windows: `.\venv\Scripts\python.exe tests\spin\test_spin_basis.py`, and so on.)
`test_spin_scalar_reduction.py` imports helpers from `test_spin_rotation_invariance.py`, so keep them in the same folder.
They are not part of `tests/run_all.py`. Runtime: seconds on a laptop GPU. The solver prints many debug lines
(`passed mass is ...`); the lines that matter start with `spin`, `largest deviation` or `PASS`.

## Reference result (RTX 3070 Laptop, 2026-10-30, commit 7853af1 plus the move to this folder)

All three print PASS; every error is at rounding level (about 1e-14 or smaller).

| script | printed numbers |
|---|---|
| `test_spin_basis.py` | largest deviation: orthonormal 6.66e-16, symmetric 1.11e-16, traceless 2.22e-16, Jz 4.16e-17, J2 1.78e-15, Jplus 8.88e-16 |
| `test_spin_rotation_invariance.py` | spin 1: rho error 3.88e-15, psi error 1.29e-14, rho changed by 29.72, uncoupled control differs by 0.98. Spin 2: rho error 2.88e-15, psi error 9.46e-15, rho changed by 19.81, control differs by 0.96 |
| `test_spin_scalar_reduction.py` | random amplitudes: spin 1 rho 1.34e-14 / psi_m 3.26e-14 / mass 0; spin 2 rho 7.79e-15 / psi_m 1.75e-14 / mass 1.86e-16; spin 3 rho 7.40e-15 / psi_m 1.46e-14 / mass 0. Single polarization m = 0: all errors exactly 0 for spin 1, 2, 3 |

On another GPU (e.g. the Koios P100) the numbers can differ in the last digits; PASS with errors around 1e-10 or
smaller is the expected outcome. A failure means a real change in the spin sector (or the test), so report it
instead of changing tolerances.

## Granule statistics result (RTX 3070 Laptop, 2026-10-30, N = 64, 100 steps, runtime about 30 s)

Printed as `variance*n`, `skewness*sqrt(n)/2`, `KS distance` (the first two should be 1, KS about 0.002 or less).

| s | n | t = 0 | t = end |
|---|---|---|---|
| 0 | 1 | 1.0044, 1.0135, 0.0011 | 0.9960, 0.9983, 0.0013 |
| 1 | 3 | 1.0023, 1.0045, 0.0010 | 0.9999, 1.0065, 0.0012 |
| 2 | 5 | 1.0025, 0.9943, 0.0011 | 0.9998, 1.0108, 0.0014 |
| 3 | 7 | 1.0002, 0.9958, 0.0012 | 0.9989, 0.9919, 0.0012 |

Finding: `Wave_vector_class` builds every `psi_m` as one amplitude times ONE shared spatial profile, so with the code's

Independent granule patterns per polarization are not generated by the code; the test supplies them itself.

## Independent-fields result (RTX 3070 Laptop, 2026-10-30, N = 64, runtime about 20 s)

`Wave_vector_class(..., independent_fields=True)` is opt-in; `power_spectrum` is a callable of |k| (flat if omitted),
`polarization_coefficients` set the mass fractions `a_m^2` (default: equal, `a_m = 1/sqrt(n)`, no random draw), phases are
ignored (irrelevant for a complex Gaussian field), `random_seed` makes the fields reproducible (a seed is drawn and
stored in `random_seed` if omitted). The default path is untouched.

Printed as `variance*n`, `skewness*sqrt(n)/2`, `KS distance` of the code's own fields:

| s | n | t = 0 | t = end |
|---|---|---|---|
| 1 | 3 | 1.0014, 0.9999, 0.0019 | 0.9969, 0.9985, 0.0009 |
| 2 | 5 | 0.9955, 0.9913, 0.0013 | 0.9991, 1.0074, 0.0011 |
| 3 | 7 | 0.9965, 0.9990, 0.0016 | 0.9964, 0.9847, 0.0018 |

Other printed numbers: component and total mass errors about 1e-16; unequal fractions (1/14, 4/14, 9/14): variance 0.4988
vs sum f^2 = 0.5000; largest cross-correlation of two components 2.1e-3 (noise level 9.8e-3); momentum factor
applied once (error 2.9e-16, mean k_x shift 2.000000 fundamentals); default path error 1.7e-16.

Windows note: if a test stops with `PermissionError` in `Scribe.save_run_config` (`os.replace` of `run_config.json`),
another process (editor/indexer) is holding the file for a moment; it is not a test failure. Run the test again.
