# Spin tests

Five plain Python scripts that check the spin (vector / tensor) part of the solver. Each prints `PASS` or raises
an `AssertionError`. They need the same CUDA/CuPy environment as the simulation. Gravity only, no baryons.

| script | what it checks |
|---|---|
| `test_spin_basis.py` | The polarization tensors of `Wave_vector_class.generate_spin_basis` are the textbook spin-s states (s = 0..4): orthonormal, symmetric, traceless, eigenstates of J_z and J^2, J_+ with Condon-Shortley phases. Pure NumPy, no GPU. |
| `test_spin_rotation_invariance.py` | Mixing the 2s+1 polarization components with a unitary matrix leaves the evolution unchanged (rho and psi' = U psi), spin 1 and 2, 100 steps. A non-mixed control proves the test can tell coupled from uncoupled. |
| `test_spin_scalar_reduction.py` | A spin-s vector whose components share one spatial profile evolves exactly like the scalar field (spin 1, 2, 3; random amplitudes and a single polarization). |
| `test_spin_granule_statistics.py` | Density granule statistics: n = 2s+1 independent white Gaussian polarization fields (N = 64, gravity off) give rho/rho_mean ~ Gamma(n, 1/n), i.e. variance(delta) = 1/n and skewness(delta) = 2/sqrt(n), and these stay unchanged under free evolution (100 steps). Also prints what the code's own amplitudes (one shared spatial profile for all components) give: variance * n = n instead of 1. |
| `test_spin_independent_fields.py` | The opt-in generator `Wave_vector_class(..., independent_fields=True, power_spectrum=None)`: every polarization gets its own Gaussian random field, `psi_m = a_m g_m`, with mass fractions `a_m^2` (equal by default). Checks that the code's own fields reproduce Gamma(n, 1/n) (s = 1, 2, 3, t = 0 and after free evolution), that unequal fractions give variance = sum f_m^2, exact component and total masses, seed reproducibility and uncorrelated components, that the momentum factor is applied exactly once, and that the default path (one shared profile) is unchanged. |

## How to run

From the repository root, with the project venv, one script at a time:

```
python tests/spin/test_spin_basis.py
python tests/spin/test_spin_rotation_invariance.py
python tests/spin/test_spin_scalar_reduction.py
python tests/spin/test_spin_granule_statistics.py
python tests/spin/test_spin_independent_fields.py
```

(Windows: `.\venv\Scripts\python.exe tests\spin\test_spin_basis.py`, and so on.)
`test_spin_scalar_reduction.py` imports helpers from `test_spin_rotation_invariance.py`, so keep them in the same folder.
They are not part of `tests/run_all.py`. Runtime: seconds on a laptop GPU. The solver prints many debug lines
(`passed mass is ...`); the lines that matter start with `spin`, `largest deviation` or `PASS`.

## Measurement: scalar vs spin 1 and 2 under gravity (`spin_gravity_comparison.py`)

Not a pass/fail test but a measurement; it prints a table (mean +- scatter over seeds) and saves plots and one `.npz` per case in
`resources/data/spin_gravity_comparison<TAG>/` (outside git). The reusable analysis functions (spin density, power spectrum,
core, collapse time, potential phase) are in `resources/Functions/spin_analysis.py`.

Run it yourself (repository root, project venv; sequential,):

```
python tests/spin/spin_gravity_comparison.py main      # spins 0, 1, 2 x seeds, N = 64 (about 15 min)
python tests/spin/spin_gravity_comparison.py conv      # spin 1 at N = 48, 64, 96 (about 15 min)
python tests/spin/spin_gravity_comparison.py report    # table and plots from the saved cases, no GPU
```

Parameters are the constants at the top of the file (N, BOX, RHO_MEAN, H, TOTAL_TIME, SAVE_EVERY, SEEDS, SPINS, K_MAX); any of
them can be overridden without editing the file, e.g. in PowerShell
`$env:RHO_MEAN='1e6'; $env:SEEDS='1,2'; $env:TAG='_mytest'; python tests/spin/spin_gravity_comparison.py main`.
Cases already saved under the same TAG are skipped, so an interrupted run can be continued. The `simulation_*` folders of the runs
(snapshots) are not deleted; their names are listed in `run_folders.txt` next to the results.

Plots: `spin_gravity_comparison.png` (variance of rho/rho_mean vs time, rho_max/rho_mean vs time, P_rho(k) at the end; mean and
scatter over seeds) and `convergence.png` (the same for N = 48, 64, 96).

### Unequal polarization fractions and the soliton onset time
`FRACTIONS=0.8,0.1,0.1` (environment variable of `spin_gravity_comparison.py`) sets the mass fractions f_m of the polarizations;
the density variance at t = 0 is then sum f_m^2 and n_eff = 1 / sum f_m^2 is the effective number of independent components
(equal fractions give n_eff = n, `1,0,0` gives n_eff = 1, i.e. the scalar field). The run folders now also contain
`max_values.csv` (`save_max_vals=True`).

The onset time of the soliton is read from the time series of `rho_max/rho_mean`: the baseline is the median of this quantity in
2-6 Gyr, the onset is the first time after 6 Gyr at which it exceeds k times the baseline (k = 3 or 5). It is a proxy, not the
soliton criterion of the literature, and only the onset time (not the values after it) is reliable at N = 64.
Spin 1, N = 64, 25 or 50 Gyr: n_eff = 1 (f = 1,0,0): 9.2 +- 1.7 Gyr (k = 3) and 9.7 +- 1.4 Gyr (k = 5), 3 seeds;
n_eff = 3 (equal fractions): 31.7 +- 5.2 Gyr and 39.6 +- 3.2 Gyr, 3 seeds; n_eff = 1.5 and 2.3 (one seed): 10.4 and 14.4 Gyr.

## Measurement scripts (not tests; GPU, results go to `resources/data/`, not in git)

| script | what it does |
|---|---|
| `spin_gravity_comparison.py` | Self-gravitating independent Gaussian fields of s = 0, 1, 2 (and n-component fields for half-integer s: s = 1.5 / 2.5 / 3.5 gives n = 4 / 6 / 8, s = 4 gives n = 9) in a periodic box; modes `main`, `conv`, `report`, settings by environment variables (see its docstring: `N, H, TOTAL_TIME, SAVE_EVERY, SEEDS, SPINS, FRACTIONS, TAG, SIM_DIR`). |
| `onset_times.py` | Soliton onset time versus the effective number of components n_eff from the saved cases (CPU, no GPU); prints the table and saves `spin_onset_vs_neff.png`. |
| `plot_peak_slice.py` | Slice through the density maximum of a snapshot, zoom, phase and profile against the soliton formula. |
| `sink_infall.py` | Phase 2 of the sink-infall study: start a new segment from a finished `spin_gravity_comparison.py` run, drop a sink at distance `DIST` from the soliton, evolve (`NOSINK=1` gives the control without the sink). Environment variables in its docstring. |
| `plot_infall.py` | Sink-to-peak distance versus time from the output of `sink_infall.py`. |
| `test_composite_components.py` | Test (run alone, `PASS`): the n-component fields for s = 1.5, 2.5, 3.5, 4 have n components of equal mass and variance(rho / rho_mean) * n = 1 within 5 %. Not part of `tests/run_all.py`. |
